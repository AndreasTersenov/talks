PhD defense slides (Andreas Tersenov, 14 September 2026): PowerPoint / Keynote version

PhD_Defense_2026_Tersenov.pptx
  Editable. Every text block is a text box, every figure a separate picture
  (full resolution, grab and reuse), cards / rules / arrows are native shapes.
  Opens in PowerPoint and Keynote. 16:9.
  - Slides 1-66 are the talk, slides 67-141 the backup.
  - Slides with a build (items replacing each other) appear once per step.
  - Display equations are pictures; each carries its LaTeX source in the
    picture's alt text (PowerPoint: right-click > View Alt Text), so it can be
    pasted into PowerPoint's equation editor if it needs editing.
  - Canvas animations appear as their final frame; the three videos are
    embedded and play on click; GIFs animate in slideshow mode.

PhD_Defense_2026_Tersenov_images_only.pptx
  Each slide is one picture of the original. Pixel-exact, not editable.

Fonts.zip
  Install these first (double-click each .ttf, or drag the folder into Font Book
  on a Mac). Without them PowerPoint substitutes other fonts and text will wrap
  differently. All are free (SIL Open Font License): Source Serif 4, IBM Plex
  Sans, IBM Plex Mono.
